# TravelEase – Flight Booking Mobile Application

### Human-Computer Interaction (HCI) & User Experience Design Project

**University of Agriculture, Faisalabad**

---

## Project Overview

**TravelEase** is a proposed flight booking mobile application designed to make flight reservations simple, convenient, and user-friendly.

This project demonstrates the fundamental concepts of Human-Computer Interaction (HCI) and User Experience (UX) design through user-centered interface design, wireframing, prototyping, and usability evaluation.

The application focuses on providing a smooth booking experience through clear navigation, organized flight information, and intuitive interface elements.

## Project Objectives

- Understand the HCI design life cycle.
- Explore Figma and its design canvas.
- Develop mobile application wireframes.
- Identify usability issues in existing flight booking services.
- Evaluate interface usability and propose improvements.
- Maintain project documentation and design resources using GitHub.

## HCI Design Life Cycle

The project follows five fundamental stages of the HCI design life cycle:

1. **Understanding Users:** Identifying travellers' needs and expectations.
2. **Identifying Problems:** Examining existing flight booking services to identify potential usability challenges.
3. Designing Solutions:** Planning a simple, consistent, and user-friendly interface.
4. **Prototyping:** Developing four mobile application screens using Figma.
5. **Evaluation:** Reviewing usability, navigation, consistency, readability, and user feedback.

## Proposed Application Screens

The TravelEase prototype consists of four main screens representing the flight booking process.

| Screen | Description |
|---|---|
| **1. Flight Search** | Enter departure city, destination, travel dates, passenger count, and travel class. |
| **2. Flight Results** | Explore available flights with airline names, ticket prices, timings, and durations. |
| **3. Seat Selection** | View the airplane seating layout and select an available seat. |
| **4. Booking Confirmation** | Review booking reference, flight details, selected seat, and total ticket price. |

##  Usability Evaluation

**Existing Application:** Google Flights

A heuristic inspection is used to investigate potential usability challenges and identify opportunities for improvement.

| Area | Proposed UX Improvement |
|---|---|
| Information Overload | Organize flight details into clear information cards. |
| Flight Comparison | Provide consistent layouts with sorting and filtering options. |
| Date Selection | Use an intuitive calendar interface. |
| Price Transparency | Display fare information and applicable additional charges clearly. |
| Booking Feedback | Provide clear status messages and guidance for the next step. |

*Note: These are evaluation areas to investigate and should be confirmed through direct observation before being reported as actual usability issues.*

## Proposed UX Improvements

TravelEase aims to enhance the flight booking experience through:

- Simple flight search with clearly labelled fields.
- Organized flight comparison cards.
- Easy-to-use date and passenger selection.
- Visual seat selection with availability indicators.
- Transparent booking summary before confirmation.
- Clear booking confirmation and reservation details.
